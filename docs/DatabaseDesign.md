# Database design

SQL Server 2022 via EF Core 8 (code-first). Entity configuration lives in
`backend/src/DevInterview.Infrastructure/Persistence/Configurations`, migrations in `Persistence/Migrations`.
Integration tests run the same model on SQLite (in-memory) and, in CI, against real SQL Server migrations.

## Conventions

- Primary keys: `Guid`, generated by the application (`ValueGeneratedNever`), so ids are known before saving.
- `BaseEntity` adds `CreatedAt`/`UpdatedAt` (UTC, stamped in `AppDbContext.SaveChanges`). Content entities also have
  `IsDeleted` (soft delete, filtered by query filters) and, where relevant, `IsActive`/`Status` (Draft/Published/Archived).
- Enums are stored as strings, except ordered scales (`Difficulty`, `ExperienceLevel`) which are stored as `int` so
  ordering and "harder than" comparisons work in SQL.
- Strings default to `nvarchar(4000)`; long text (bodies, explanations, code, AI output) is `nvarchar(max)`.
- AI cost estimates: `decimal(18,6)`; plan prices in micros (`long`); other decimals (scores, percentages) use EF's default precision.
- Deleting content never deletes learner history: attempts/submissions reference soft-deleted rows.

## Uniqueness and integrity constraints

| Constraint | Why |
|------------|-----|
| `Technologies.Slug`, `(Categories.TechnologyId, Slug)`, `(Topics.CategoryId, Slug)`, `LearningPaths.Slug`, `Companies.Slug`, `CodingChallenges.Slug` | Stable URLs / import keys |
| `Questions.ExternalKey`, `CodingChallenges.ExternalKey`, `Flashcards.ExternalKey` (filtered, not null) | Idempotent seed/import upserts |
| `QuestionAnswers.QuestionId` | One answer per question |
| `(QuestionBookmarks.UserId, QuestionId)`, `(QuestionNotes.UserId, QuestionId)` | One bookmark/note per user and question (sync LWW) |
| `(SavedCollections.UserId, Name)`, `(SavedCollectionItems.CollectionId, ItemType, ItemId)` | No duplicates |
| `Quizzes.DailyDate` (filtered) | Exactly one daily quiz per day |
| `(QuizQuestions.QuizId, QuestionId)`, `(QuizAttemptAnswers.AttemptId, QuestionId)` | No duplicate questions/answers |
| `(CodeSubmissions.UserId, IdempotencyKey)` (filtered) | Retried submits are not double-counted |
| `(ChallengeStarterCodes.ChallengeId, LanguageCode)` | One template per language |
| `(MockInterviewQuestions.InterviewId, Sequence)`, `MockInterviewAnswers.QuestionId`, `MockInterviewEvaluations.InterviewId` | Ordered, single answer, single report |
| `(UserLearningProgress.UserId, LessonId)` | One progress row per lesson |
| `(FlashcardReviews.UserId, FlashcardId)`, `(FlashcardReviewLogs.UserId, ClientReviewId)` | One schedule per card; offline reviews applied once |
| `(UserXpTransactions.UserId, SourceType, SourceKey)` | XP is awarded once per event |
| `(UsageCounters.UserId, Feature, Date)` | Atomic daily quota counters |
| `(UserAchievements.UserId, AchievementId)`, `Achievements.Code`, `UserStreaks.UserId` | Single award / streak row |
| `(UserPerformanceStats.UserId, TechnologyId)` | Aggregates per technology |
| `RefreshTokens.TokenHash`, `Users.GoogleSubjectId` (filtered) | Token lookup; one Google account per user |
| `(AiPromptTemplates.Key, Version)`, `AiProviderSettings.ProviderName`, `AppSettings.Key`, `SupportedLanguages.Code` | Versioned prompts and settings |

Additional non-unique indexes cover common filters: questions by technology/category/status/difficulty, attempts and
submissions by user and date, notifications by user/read state, audit logs by entity and date, activity logs by date.

## Sensitive data

- Passwords: Identity PBKDF2 hashes only. Refresh tokens: SHA-256 hashes only.
- Purchase tokens: hashed for lookup (`PurchaseTokenHash`); the raw token is kept for server-side re-verification and
  never returned by any endpoint.
- Account deletion anonymises the user row (email/name replaced, login disabled) and deletes personal content
  (notes, bookmarks, collections, notifications, reminders, AI evaluations and code reviews, devices, tokens) while
  keeping anonymous aggregate history.
- Audit log details mask keys containing password, token, secret, apikey, signingkey or credential.

## Migrations

```bash
cd backend
dotnet tool restore
dotnet ef migrations add <Name> -p src/DevInterview.Infrastructure -s src/DevInterview.API -o Persistence/Migrations
dotnet ef migrations has-pending-model-changes -p src/DevInterview.Infrastructure -s src/DevInterview.API
```

Never edit an applied migration. For reviewed production rollouts generate an idempotent script with
`scripts/DatabaseSetup/generate-migration-script.sh`.
